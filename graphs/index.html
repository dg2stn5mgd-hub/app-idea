Plot y = f(x)

    Write powers with ^, like x^2. You can use e^x, ln x, sqrt(x), |x|, sin x and pi. Values are found numerically. Simple exact values like 3/2 or √3 are recognised; anything else is given to 3 s.f.

    What to look for on any graph

    • Intersections with the axes. Put x = 0 to get the y-intercept, and solve y = 0 for the x-intercepts. Always write them as coordinates, e.g. (0, −4).
    • Turning points. These are where dy/dx = 0. Say whether each one is a maximum or a minimum. On the GC use G-Solv → MAX / MIN, or CALC → maximum / minimum on a TI.
    • Vertical asymptotes x = k are where the denominator is zero but the numerator isn't. The curve shoots off to ±∞ there.
    • Horizontal asymptotes y = k come from what y tends to as x → ±∞. Oblique asymptotes y = mx + c come from long division.
    • Symmetry. If f(−x) = f(x), the graph is symmetric about the y-axis (an even function). If f(−x) = −f(x), it has rotational symmetry about the origin (an odd function).

    Don't trust the GC screen alone.

    • A GC often draws a steep near-vertical line at an asymptote. That line is not part of the curve.
    • Pick a sensible window. Zoom out to see how the curve behaves as x → ±∞, and zoom in to see turning points that sit close together.
    • Give answers to 3 s.f. unless the question asks for exact values. Use the algebra (below) whenever an exact answer is asked for.

    Transformations of y = f(x)

    Four basic moves cover every transformation in the syllabus. Changes outside the f act on y and do what you'd expect. Changes inside the f act on x and do the opposite of what they look like.

    Build a sequence of transformations

    Choose a starting curve, then add transformations one at a time. The equation is updated after each step. The marked points and asymptotes show where everything ends up.

    Start with y = f(x)
    Then apply, in order

      Order matters

      Two translations commute, and so do two scalings. But a translation and a scaling in the same direction don't. Look at y = f(2x + 6):

      • Translate first: f(x) → f(x + 6), a translation of 6 units in the negative x-direction. Then replace x by 2x to get f(2x + 6), a scaling parallel to the x-axis by factor ½. ✓
      • Scale first: f(x) → f(2x). Then you need f(2(x + 3)), so replace x by x + 3. That's a translation of only 3 units in the negative x-direction. ✓
      • Wrong: scale by ½ and then translate 6 units. That gives f(2(x + 6)) = f(2x + 12). ✗

      The trick: each step replaces x with something. It doesn't touch the numbers already in the bracket. Work it out one replacement at a time and you won't go wrong. Try both orders in the builder above.

      Worked examples

      The curve y = f(x) undergoes, in succession, (A) a translation of 2 units in the positive x-direction, (B) a scaling parallel to the y-axis by a factor of 3, (C) a translation of 1 unit in the negative y-direction. Find the equation of the new curve.

      Show solution
      1. (A) Replace x by x − 2: y = f(x − 2)
      2. (B) Replace y by y/3: y/3 = f(x − 2), so y = 3f(x − 2)
      3. (C) Replace y by y + 1: y + 1 = 3f(x − 2), so y = 3f(x − 2) − 1
      4. The point (4, 5) on y = f(x) maps to (6, 5) → (6, 15) → (6, 14).

      Describe a sequence of transformations that maps the graph of y = 1/x onto the graph of y = (2x + 5)/(x + 1).

      Show solution
      1. Divide first: 2x + 5 = 2(x + 1) + 3, so y = 2 + 3/(x + 1).
      2. 1/x → 1/(x + 1): a translation of 1 unit in the negative x-direction.
      3. → 3/(x + 1): a scaling parallel to the y-axis by a factor of 3.
      4. → 3/(x + 1) + 2: a translation of 2 units in the positive y-direction.
      5. Check with the asymptotes: x = 0, y = 0 move to x = −1, y = 2. ✓

      The graph of y = f(x) has a maximum point at (2, 6) and asymptotes x = 1 and y = 3. Find the corresponding features of y = 2f(−x) + 1.

      Show solution
      1. Point: x → −x reflects in the y-axis, then y → 2y + 1. So (2, 6) → (−2, 6) → (−2, 13).
      2. A positive scaling keeps a maximum as a maximum, so (−2, 13) is still a maximum. (A negative factor would turn it into a minimum.)
      3. Vertical asymptote x = 1 → x = −1. Horizontal asymptote y = 3 → y = 2(3) + 1 = 7.

      Practice: describe the transformations

      Common mistakes

      • Writing "scaling by factor 2" for y = f(2x). Changes inside the bracket do the opposite: the factor is ½, parallel to the x-axis.
      • Translating the wrong way: y = f(x − 3) moves the curve 3 units in the positive x-direction.
      • Leaving out "parallel to the x-axis / y-axis", or the direction of a translation. You lose marks without them.
      • Forgetting the asymptotes. Transform them as well, using the same rules as for points.

      Rational functions: y = (ax + b)/(cx + d)

      Every one of these curves is a rectangular hyperbola. It's just y = 1/x moved and stretched. Divide it out to see how.

      y = ax + bcx + d = ac + bc − adc(cx + d)
      • Vertical asymptote: the denominator is zero, so x = −d/c.
      • Horizontal asymptote: as x → ±∞, y → a/c, so y = a/c.
      • Restrictions: x ≠ −d/c, and y can take every real value except a/c.
      • The two asymptotes cross at (−d/c, a/c). The curve has rotational symmetry about this point. Both lines through it at gradient ±1 are also lines of symmetry.
      • No turning points: the gradient (ad − bc)/(cx + d)² never changes sign.
      Change a, b, c, d

        Sketch y = (2x − 1)/(x + 3), stating the equations of the asymptotes and the coordinates of the points where the curve crosses the axes.

        Show solution
        1. Write it as y = 2 − 7/(x + 3).
        2. Asymptotes: x = −3 and y = 2.
        3. x = 0 gives y = −1/3, so the curve crosses the y-axis at (0, −1/3). y = 0 gives 2x − 1 = 0, so it crosses the x-axis at (1/2, 0).
        4. Because of the −7, the branches sit in the top-left and bottom-right of the asymptotes: as x → −3⁺, y → −∞.

        Rational functions: y = (ax² + bx + c)/(dx + e)

        A quadratic over a linear. Long division gives a straight line plus a small leftover. That line is the oblique asymptote.

        y = ax² + bx + cdx + e = px + q + rdx + e
        • Vertical asymptote: x = −e/d.
        • Oblique asymptote: y = px + q, because r/(dx + e) → 0 as x → ±∞.
        • The curve has two turning points when r/a > 0 and none when r/a < 0. If r = 0, the "curve" is just a straight line with a hole in it.
        • Range by the discriminant. Rearrange y(dx + e) = ax² + bx + c into a quadratic in x. For a real x to exist, its discriminant must be ≥ 0. Solving that inequality gives the possible values of y.
        Change a, b, c, d, e

          For the curve y = (x² + x + 4)/(x − 1), find the asymptotes and the set of values that y cannot take. Hence find the turning points exactly.

          Show solution
          1. Long division: x² + x + 4 = (x − 1)(x + 2) + 6, so y = x + 2 + 6/(x − 1).
          2. Asymptotes: x = 1 and y = x + 2.
          3. y(x − 1) = x² + x + 4 rearranges to x² + (1 − y)x + (4 + y) = 0.
          4. Real x needs (1 − y)² − 4(4 + y) ≥ 0, which simplifies to y² − 6y − 15 ≥ 0.
          5. The roots are y = 3 ± 2√6, so y ≤ 3 − 2√6 or y ≥ 3 + 2√6. y cannot take values in (3 − 2√6, 3 + 2√6).
          6. The boundary values are the y-coordinates of the turning points. At those values the quadratic has a repeated root, x = (y − 1)/2. This gives max (1 − √6, 3 − 2√6) and min (1 + √6, 3 + 2√6).
          7. No x-intercepts, since x² + x + 4 = 0 has discriminant −15 < 0. The y-intercept is (0, −4).

          Common mistakes

          • Drawing the curve crossing its vertical asymptote. It never can.
          • Sketching the oblique asymptote without its equation, or without its intercepts on the axes.
          • Flipping the inequality from the discriminant. The y-values outside the two roots are allowed when the coefficient of y² is positive.

          Ellipses and hyperbolas: x²/a² ± y²/b² = 1

          With a plus sign you get an ellipse, a closed oval. With a minus sign you get a hyperbola: two branches that approach a pair of slant asymptotes.

          EquationShapeKey pointsAsymptotesRestrictions
          x²/a² + y²/b² = 1Ellipse (a circle if a = b)(±a, 0), (0, ±b)None−a ≤ x ≤ a, −b ≤ y ≤ b
          x²/a² − y²/b² = 1Hyperbola, opens left and rightVertices (±a, 0)y = ±(b/a)xx ≤ −a or x ≥ a
          y²/b² − x²/a² = 1Hyperbola, opens up and downVertices (0, ±b)y = ±(b/a)xy ≤ −b or y ≥ b

          Replacing x by x − h and y by y − k moves the centre to (h, k). The lines of symmetry become x = h and y = k, and the asymptotes become y − k = ±(b/a)(x − h).

          Choose a conic

            Sketch (x − 1)²/4 + (y + 2)²/9 = 1, and state the restrictions on x and y.

            Show solution
            1. It's an ellipse with centre (1, −2), a = 2 and b = 3.
            2. Ends of the axes: (1 ± 2, −2) = (−1, −2) and (3, −2). (1, −2 ± 3) = (1, 1) and (1, −5).
            3. Restrictions: −1 ≤ x ≤ 3 and −5 ≤ y ≤ 1. Lines of symmetry: x = 1 and y = −2.
            4. y-intercepts: put x = 0, so (y + 2)²/9 = 3/4 and y = −2 ± 3√3/2. Plot them on the sketch.

            Find the asymptotes of 4x² − 9y² = 36, and the coordinates of its vertices.

            Show solution
            1. Divide by 36: x²/9 − y²/4 = 1, so a = 3 and b = 2.
            2. Vertices: (±3, 0). Asymptotes: y = ±(2/3)x.
            3. A quick way to get the asymptotes: replace the 1 with 0. Then x²/9 = y²/4, so y = ±2x/3.

            Sketching checklist

            Most of the marks for a sketch come from labels, not from the shape. Before you move on, check you've done each of these.

            1. Asymptotes drawn as dashed lines, with their equations written on them.
            2. Axial intercepts labelled as coordinates. Exact where you can, otherwise 3 s.f.
            3. Turning points labelled as coordinates.
            4. The curve approaches each asymptote without crossing a vertical one, and the branches bend the right way.
            5. The shape near the ends is right: what happens as x → ±∞?
            6. Any restricted domain is shown, with endpoints drawn as solid or hollow dots as needed.
            7. For a transformation question, label the new points and asymptotes, not the old ones.
